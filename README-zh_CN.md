## 🌟 模组简介

**酒狐的魔法书** 让《车万女仆》里的女仆成为真正的法师：把法术书放进她的饰品栏，她就会在战斗中依据局势自行挑选法术、计算魔力、规避冷却、走位周旋，并在使用 GeckoLib 模型时播放咏唱动作。

除女仆施法这条主线外，模组还提供：

- **灵狐学派**——自带伤害类型与专属属性的独立学派，核心是**玩家与女仆的配合**：玩家起手、女仆接力，协同作战的收益远高于各自为战；
- **附属兼容**——为 15 个《Iron 的法术与魔法书》附属的数百个法术做了行为分类，已安装则生效，未安装也不报错。

关于名字：咏唱动画只有 GeckoLib 模型的女仆才能播放，而「酒狐」正是这样一款女仆模型。

## ⚡ 快速上手

1. 安装前置：**车万女仆（Touhou Little Maid）** 与 **《Iron 的法术与魔法书》（Iron's Spells 'n Spellbooks）**，以及它们各自的前置（Curios、GeckoLib）。
2. 安装本模组。
3. 给女仆一本刻好法术的**法术书**，放进她的**饰品栏**；或者给她一件**注魔的武器 / 盔甲**。
4. 打开女仆 GUI，把任务切换到 **法术攻击** 或 **法术支援**。
5. 开启「法术战斗中显示法术名称」（默认开启）后，即可在她头顶看到当前施放的法术。

## 🧙 女仆施法

### 施法媒介

女仆的**主手、盔甲栏、女仆饰品栏、Curios 栏**都会被扫描，其中任何「法术容器」（法术书、注魔武器、注魔盔甲）里的法术都会进入她的法术表。

- 多本法术书**只有一本生效**（与玩家一致）；注魔装备不受此限，可以叠加。
- 法术等级 = 法术本身的等级 + 装备上的亲和（Affinity）加成。
- **不属于任何行为分类的法术会被直接忽略**——这是「女仆始终不施放某个法术」最常见的原因，详见[七个行为分类](#七个行为分类)。
- 装备一经变动，法术表立即重算；`/reload` 更新法术标签后，已加载的女仆也会重新扫描。

### 两种任务

| 任务 | 会用的法术分类 | 作用目标 |
|---|---|---|
| **法术攻击** | 攻击 / 防御 / 移动 / 自我治疗 / 负面效果 | 自己的仇敌 |
| **法术支援** | 防御 / 自我治疗 / 增益队友 / 负面效果 / 治疗队友 | 主人和友军正在攻击的目标 |

**法术攻击**是常规战斗位：主动索敌、走位、施法，还可以按配置使用近战武器补刀。

**法术支援**不主动开战，专职为主人和同阵营生物（包括同主人的其他女仆）治疗、施加增益、清除负面，同时也会给敌人施加负面效果。

> 两个任务的启用条件相同：主手或盔甲栏有注魔武器，或饰品栏有刻了法术的法术书。

### 七个行为分类

女仆的法术表按行为分为七类，游戏内配置界面用的也是这套名称。同一分类在法术标签和配装数据包中另有英文字段名，对照如下：

| 分类 | 法术标签 | 配置项（键名） | 配装 `spells` 字段 |
|---|---|---|---|
| 攻击 | `attack_spells` | 额外的攻击法术ID（`extraAttackSpells`） | `attack` |
| 防御 | `defense_spells` | 额外的防御法术ID（`extraDefenseSpells`） | `defense` |
| 移动 | `movement_spells` | 额外的移动法术ID（`extraMovementSpells`） | `movement` |
| 自我治疗 | `support_spells` | 额外的自我治疗法术ID（`extraSupportSpells`） | `support` |
| 增益队友 | `positive_effect_spells` | 额外的增益队友法术ID（`extraPositiveEffectSpells`） | `positive_effect` |
| 负面效果 | `negative_effect_spells` | 额外的负面效果法术ID（`extraNegativeEffectSpells`） | `negative_effect` |
| 治疗队友 | `support_effect_spells` | 额外的治疗队友法术ID（`extraSupportEffectSpells`） | `support_other` |

另有两个不参与分类的**标记标签**：`summon_spells`（召唤类）与 `maid_should_recast_spells`（需要多次咏唱），二者仅作标记，不决定女仆能否施放该法术。

### 魔力

- 女仆有**独立于玩家**的魔力条，用 Jade 指向她即可查看。
- 上限与玩家同一套算法：法杖、法师套装上的「最大法力值」词条同样生效，也可用配置项「最大法力值倍率」整体缩放。
- 自然回复默认约 **每秒 2%**，受魔力恢复词条影响。
- **被闪电击中过**是写进女仆存档的永久标记，被劈中一次即永久生效。开启「被雷劈过的女仆魔力恢复速度 ×100」后，这类女仆每 0.5 秒回满整条魔力，近乎无限法力——该选项**默认关闭**。

### 女仆如何选择法术

女仆每隔很短一段时间决策一次（间隔上限由「最大施法间隔刻」控制，默认最多 10 刻）：

1. **排除当前无法施放的法术**：魔力不足或仍在冷却的一律排除；若尚有未完成的多段咏唱，则优先将其施放完毕。
2. **为每个行为分类计算权重**，加权随机抽取一类，再在该类中等概率抽取一个法术。

权重的几条基本规律：

- 队友血量越低，「治疗队友」的权重越高，**濒死队友的优先级高于一切**；
- 附近有队友**需要支援**（掉血、缺少增益、身上有可驱散的负面效果或魔力不足），且女仆手上有对应的可用法术时，支援类优先，战斗类不参与本轮抽取；队友无需支援时照常战斗。只有召唤女仆会同时携带两类法术，自家女仆的两个任务各自只用其中一类；
- 自身血量越低，「防御」和「移动」的权重越高；
- 看不见目标时基本不会选择攻击类，转而以位移绕开；
- 队友缺少某个增益、或身上有可驱散的负面效果时，对应法术的权重会显著提高；
- 上一轮选过防御 / 负面效果时，这两类的权重会被调低，避免连续施放同一类。

索敌半径由「法术攻击最大索敌范围」（默认 64 格）决定，**带有[残月烙印](#-灵狐学派)的敌人会被优先选中**。女仆需要接近到「法术施放开始距离」（默认 15 格）或该法术自身的施法距离之内才会起手。

其他战斗行为：

- **走位**：距离小于射程一半时后撤，在射程内且有视线时原地绕圈；施法期间移速放慢；被命令坐下时不再走位。
- **近战补刀**：由配置项「允许女仆在法术攻击时使用近战武器」控制，默认开启。

### 咏唱动画

模组把《Iron 的法术与魔法书》的咏唱动作接入了车万女仆的动画系统，使用 GeckoLib 模型的女仆施法时会播放对应动作。

模型包作者可以在自己的动画文件里定义 `iss:` 前缀的动画片段来自定义咏唱动作，键名可参考[车万女仆的 iss.animation.json](https://github.com/TartaricAcid/TouhouLittleMaid/blob/1.21/src/main/resources/assets/touhou_little_maid/animation/iss.animation.json)。

> 动画资源由《Iron 的法术与魔法书》的原版动画转换而来，个别姿势可能存在骨骼错位，将在后续版本继续修正。

## 🍶 灵狐学派

**灵狐（Vulpine）** 是本模组新增的独立学派，拥有自己的伤害类型与两条属性（灵狐法术强度 / 灵狐抗性），可与《Iron 的法术与魔法书》本体的法师套装词条混搭。

这是一个**为「玩家 + 女仆」设计的学派**：法术大多在玩家与女仆之间往复传递收益——玩家先烙下印记、女仆接力引爆，玩家施放的披风与解控也会一并覆盖身边的女仆。单人同样可用，但与一队女仆协同作战才是它的完整形态。

学派仍在扩充中，后续版本会继续加入新的玩法方向。

|---|---|---|

### 烙印引爆与酒涌

目前学派里最能体现「玩家 + 女仆」配合的一条机制：

1. 用**残月烙印**为敌人烙下印记（基础 12 秒，每级 +1 秒）。
2. 对其造成任意**灵狐伤害**——酒杯狐影、狐影伏击的咬击、狐酿炸弹直击均可。
3. 烙印随即引爆：伤害 = 基础 10 点 + 施加烙印时的法术强度。
   - **玩家引爆**：半径 3 格，不连锁；
   - **自家女仆引爆**：伤害 ×1.5、半径 4 格（玩家身上的酒涌满层时为 5 格），并且能**连锁引爆**下一个带有烙印的目标。
4. 每次引爆都为玩家叠加一层**酒涌**：10 秒滚动刷新，最多 3 层，每层 **+10% 学派法术强度**。女仆引爆同样计入玩家。

烙印自然到期时只会在 2 格内小幅自爆一次（3 点原版魔法伤害，不叠加酒涌、不触发连锁）。

概括来说：玩家负责施加烙印，女仆负责引爆——引爆衔接得当，酒涌便不会中断。

### 微醺

**微醺**是中性效果，不造成伤害，但会让中招者：

- 移动速度 −30%（按效果等级缩放）；
- 行走踉跄、朝向随机抖动（玩家的视角由客户端掌控，因此不受抖动影响）；
- 射出的箭矢等弹射物大幅偏离。

自家女仆对醉狐之雾与酒池免疫。

### 召唤女仆

学派中的一个法术：召出一队临时女仆，协助打完当前这场战斗。

- 数量随等级增长（1 级 2 只，6 级 7 只，法术强度装备还能再往上抬），持续 **10 分钟**。召唤期间再次施放该法术不会追加一队，而是提前遣散已召出的女仆。
- 每只女仆随机选取模型，并按召唤等级抽取装备与法术；有概率骑乘**扫帚**升空，在召唤者上方盘旋施法。
- 她们**不能交互、不接受指令、不会坐下**，只跟随召唤者作战；**死亡不掉落装备**，到期自行消散。默认还会让苦力怕主动避开她们。

三套内置配装（可被数据包替换或扩充）：

| 配装 | 出现权重 | 扫帚 | 定位 |
|---|---|---|---|
| **warrior** | 40 | 从不 | 攻击法术为主，护甲最完整 |
| **mage** | 35 | 允许 | 攻击 + 负面效果 + 少量防御 / 移动 |
| **support** | 25 | 允许 | 治疗队友 + 增益队友 + 少量攻击 |

按召唤等级分三层：1–2 级、3–4 级、5–6 级；层级越高，护甲越完整、法术越多、可携带的法术等级上限也越高。

> ⚠️ **召唤女仆目前强度偏高，后续版本会继续追加平衡性限制**（数量、持续时间、可携带法术等均可能调整）。
> 如需立即削弱，可在配置的「召唤出的女仆」一栏调整上限——默认已限制在 3 级法术、史诗稀有度以内，也不会随机到习得制学派（即邪术）的法术；也可以用数据包替换配装。

## ⚙️ 配置

全部为**服务端配置**（多人游戏以服务器的设置为准），可在模组列表的配置界面直接修改，也可编辑 `<存档>/serverconfig/winefoxs_spellbooks-server.toml`。下表第二列为文件中的键名。

### 战斗与 AI

| 界面名称 | 键名 | 默认 | 说明 |
|---|---|---|---|
| 法术攻击最大索敌范围 | `maxSpellRange` | 64 | 索敌半径（8–192）。调大会增加索敌开销 |
| 法术施放开始距离 | `startSpellRange` | 15 | 起手施法距离（2–64），可被单个法术的施法距离覆盖 |

## 📦 数据包定制

### 排除法术

女仆可用的法术由**法术标签**决定。若要禁止某个法术（例如误伤严重的范围法术），需用数据包将其从标签中移除。

新建 `<存档>/datapacks/<数据包名>/pack.mcmeta`：

```json
{ "pack": { "pack_format": 48, "description": "女仆法术黑名单" } }
```

再新建 `<数据包名>/data/winefoxs_spellbooks/tags/irons_spellbooks/spells/attack_spells.json`：

```json
{
  "values": [],
  "remove": [
    { "id": "irons_spellbooks:fireball" }
  ]
}
```

执行 `/reload` 即可生效：法术目录立即重建，已加载的女仆也会重新扫描法术表。

**行为标签**（一个法术只属于其中一类，从它所在的标签中移除即可；各分类对应的标签名见[七个行为分类](#七个行为分类)）。

要查某个法术属于哪个标签，用压缩软件打开本模组的 jar，进入 `data/winefoxs_spellbooks/tags/irons_spellbooks/spells/` 目录——七个行为标签与两个标记标签的 json 都在其中，内容即默认分类，照此改写为自己的数据包即可。

**标记标签**——从 `summon_spells` 或 `maid_should_recast_spells` 中移除只会去掉召唤 / 多次咏唱标记，女仆仍会施放该法术。

> ⚠️ 配置项在标签之后合并，因此不要把同一个法术 ID 再写入 `extraAttackSpells` 之类的列表，否则会被重新加回。

### 施法距离与附带效果

路径 `data/<命名空间>/magic_maid_spell_data/`：

- `default_casting_range.json`——女仆起手施放各法术的距离；
- `default_caused_effect.json`——声明某个法术会施加哪种药水效果，女仆据此判断是否重复施加同一增益、以及目标身上的负面是否需要驱散。

两者均随 `/reload` 生效，配置文件中的同名项优先于数据包。

### 召唤女仆配装

路径 `data/<命名空间>/summoned_maid_loadouts/<名称>.json`，最小骨架：

```json
{
  "weight": 40,
  "broom_mode": "default",
  "tiers": [
    {
      "conditions": [
        { "condition": "winefoxs_spellbooks:summon_level", "min": 1, "max": 2 }
      ],
      "spell_level_cap": 3,
      "weapon": {
        "rolls": 1,
        "entries": [ { "type": "tag", "expand": true, "name": "modid:weapon_tag" } ]
      },
      "armor": {
        "helmet": {
          "chance": 0.3,
          "pools": [ { "rolls": 1, "entries": [ { "type": "tag", "expand": true, "name": "modid:helmet_tag" } ] } ]
        }
      },
      "spells": {
        "attack": {
          "rolls": { "min": 1, "max": 2 },
          "entries": [ { "type": "tag", "expand": true, "name": "modid:attack_spells" } ]
        }
      }
    }
  ]
}
```

字段说明：

- `weight`——被选中的权重，`0` 表示禁用；
- `broom_mode`——`always` / `never` / `default`（按概率决定）；
- `model_filter`（可选）——`{ "mode": "all" | "allowlist" | "denylist", "models": [...] }`；
- `tiers[].conditions`——目前支持 `winefoxs_spellbooks:summon_level` 的 `min` / `max` 区间；
- `tiers[].spell_level_cap`——该层法术等级上限，与配置项取小；
- `tiers[].weapon` / `armor` / `spells`——物品与法术池，`rolls` 支持整数或 `{ "min": n, "max": m }`，条目用物品标签 / 法术标签引用；
- `spells` 的键就是七个行为分类：`attack`、`defense`、`movement`、`support`、`positive_effect`、`negative_effect`、`support_other`（对照见[七个行为分类](#七个行为分类)）。

内置的 `warrior.json`、`mage.json`、`support.json` 可直接用作模板。

### 晨间礼物掉落

晨间礼物的内容由战利品表 `winefoxs_spellbooks:gameplay/maid_morning_gift` 决定（默认 95% 掉落一个灵狐精魂），整合包可直接覆盖它来替换奖励。

## 💻 指令

需要 OP 2 级权限：

```
/wsb cast <targets> <spell> [level]
/wsb summon [target] [count] [summonLevel] [loadout] [duration] [airForce]
```

- `/wsb cast`——让指定实体施放某个法术，等级 1–10。该指令只跳过起手前的可用性检查，**仍会消耗魔力**，测试前建议先提高目标的魔力上限。
- `/wsb summon`——不带参数时为自己召唤。`count` 1–10，`summonLevel` 1–10，`loadout` 填配装 ID（留空则随机），`duration` 为秒数（`-1` 表示永久），`airForce` 强制指定是否骑乘扫帚。

### 车万女仆：万法皆通

安装车万女仆：万法皆通后，任务、法术书栏位与饰品以万法皆通为准，铁魔法的施法由本模组负责：

- **任务**——不再注册「法术攻击」任务，改用万法皆通的「法术战斗」（近身）或「远程法术」任务。两者中女仆均按本模组的逻辑选择并施放铁魔法法术，战斗中也会为主人和队友治疗、增益。「法术支援」任务保留，供只需支援的女仆使用。
- **法术书**——按万法皆通的规则识别：副手、主手、背包与 Curios，可同时生效多本。放在车万女仆饰品栏中的法术书不再生效，需自行移出。
- **站位**——「法术战斗」贴近目标，「远程法术」与目标保持距离；射程不足该距离的攻击法术在「远程法术」中不会被选用。
- **冷却**——由万法皆通记录，其冷却倍率与冷却类饰品均会生效。法力照常消耗，可通过 `tlmSpellMana` 关闭。
- **饰品**——法术白名单：名单中本模组不会对队友施放的法术，改为对主人施放。坐下或骑乘时施法需佩戴法术射表，与万法皆通一致。
- **其他魔法模组**——同一时间只施放一个法术。铁魔法优先，其冷却或法力不足时由其他模组的法术补上。
- **末影腰包**——女仆列表在血条下方显示法力条。

## ❓ 常见问题

**女仆完全不施法？** 按顺序排查：

1. 任务是否切到了「法术攻击 / 法术支援」？
2. 法术书是否在**饰品栏**？书中的法术槽是否已铭刻？
3. 该法术是否属于某个行为标签？**不属于任何行为分类的法术会被直接忽略**。
4. 魔力是否充足？冷却是否结束？气泡显示「冷却中」即为这两者之一。
5. 敌人是否超出「法术攻击最大索敌范围」，或她尚未进入「法术施放开始距离」？

**女仆的范围法术总在误伤队友？** 用[数据包](#排除法术)把该法术从行为标签中移除，再 `/reload` 即可。

**改了配置没有生效？** 「法术兼容」一段的改动需要重启游戏；数据包相关的改动 `/reload` 即可。

**女仆为什么不会施放「召唤女仆」？** 这是有意为之——该法术只保留给玩家（以及 `/wsb summon`），女仆不会用它再召出一队女仆。

**支援女仆始终不为队友治疗？** 法术支援任务只作用于同阵营目标；此外她还需带有对应分类的法术（治疗队友 / 增益队友）才会切换到支援行为。
